SILVA DEV PORTFOLIO

Open index.html in your browser to view the portfolio.
The CSS and JavaScript are included inside index.html. Keep the image files and icon.svg beside it.
No installation or build command is required.

Hosting: Upload all files to a static hosting service such as Vercel, Netlify or GitHub Pages. Use the folder containing index.html as the website root.

Contact: WhatsApp and email links are configured. The enquiry form opens an email draft; the visitor must send it from their email app. It does not send from a server.
Google Fonts requires an internet connection; system fonts are the fallback.

If you change the hosting address, update the og:url metadata in index.html.
